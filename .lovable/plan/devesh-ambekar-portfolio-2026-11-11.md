# Devesh Ambekar Portfolio

## Goal
Replace the placeholder home page with a polished, fully responsive personal portfolio that presents Devesh's supplied profile, projects, education, leadership and contact details.

## Plan
- Establish a distinctive dark visual system and build the home page as a long-form portfolio with sticky navigation, responsive mobile menu, section links and back-to-top control.
- Add the requested hero, about, categorized skills, detailed project cards and dialogs, leadership timeline, education, coding profiles, validated contact form with mailto fallback, and footer.
- Provide a resume download using only the supplied facts, and a custom DA favicon.
- Add page-specific metadata, preserve accessible controls and reduced-motion behavior, and verify the home page and its main interactions at desktop and mobile sizes.

## Technical details
- Keep the experience frontend-only; no persistence or external service is required for this portfolio.
- Use the existing TanStack Start, Tailwind design tokens, shadcn controls, Lucide icons, and Zod validation already available in the project.
- Record the single-page portfolio structure in `AGENTS.md`, and track the multi-section delivery in `roadmap.md`.
