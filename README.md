## 2. DESIGN DIRECTION
Create an elegant, premium, dark-themed developer portfolio inspired by high-quality contemporary technology portfolios.
Visual characteristics:
- Deep black and charcoal backgrounds (#090B10, #11151D, card bg: #151B26)
- Subtle dark gradients and borders (#7C8CFF primary accent, #A78BFA secondary accent, #F5F6FA primary text, #A0A8B8 secondary text)
- Minimalist layouts with strong visual hierarchy, generous whitespace, glassmorphism used sparingly
- Smooth transitions, micro-interactions, subtle glow/ambient lighting
- Typography: modern professional sans-serif (Inter / Manrope)
Avoid: Generic template aesthetics, excessive neon effects, overloaded gradients, cartoonish illustrations, fake statistics/testimonials.
